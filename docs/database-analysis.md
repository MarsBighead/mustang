## 注意事项

1. **硬链接**: 微信大量使用硬链接，相同 inode 的文件不算重复
2. **增量扫描**: 再次运行 analyze 会跳过未改变的文件
3. **WAL 模式**: 数据库使用 WAL 模式，会产生 `-wal` 和 `-shm` 文件
4. **quarantine 可恢复**: 被隔离的文件可以手动恢复
